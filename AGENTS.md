## Hardware and driver ownership

Read [docs/HARDWARE_AGNOSTIC_DRIVER_BOUNDARY.md](docs/HARDWARE_AGNOSTIC_DRIVER_BOUNDARY.md) before any hardware, driver, transport, device or registry work. Core sees opaque capability identifiers including `usb` and `serial.port`, supplying generic package/ELF loading, contexts, permissions, resolver, streams/events and lifecycle. Normal firmware must not own USB discovery, chipset/class/provider selection, sessions/transfers, VBUS or fallback. Independently installed physical provider ELFs own actual device/controller communication, probing, arbitration, protocol and safe teardown. Thin proxy ELFs forwarding to compiled-in hardware are noncompliant. Isolated bootstrap/recovery may provide CPU/RTOS/storage primitives, never silent production fallback. CPU/ABI ports differ; compatible new hardware on the same port should need drivers/profiles, not firmware modification. Use RiscRTE for platform, CrossPoint for reader subsystem/compatibility only; use context-owned opaque/generation-safe handles. Installing a manifest does not grant physical access.

## Versions, packages and releases

Every changed distributable app, driver, service or provider MUST advance its own manifest numeric version above merge-base and latest published lineage in the same PR. Stable `id` is upgrade lineage; numeric package version differs from ABI, architecture and capability API. Do not create `foo-v2` simply to hide upgrade/version checks. Inspect source/published baseline, record old -> new and match manifest/archive/catalog/installed identities. Modified Apps require `Apps/<name>.json` bump; changed drivers require their manifests. No unrelated bump for docs-only edits or claims that nonimplemented automatic guards passed. Repair `usb-cdc-acm`/`usb-cdc-acm-v2` with canonical ID, increased version, safe installed migration/quiescence/rollback and actual prevention gates. Read [Apps/AGENTS.md](Apps/AGENTS.md) and [Drivers/AGENTS.md](Drivers/AGENTS.md) when relevant.

Current distribution is one `.rte.zip` archive per package plus generic catalog, with manifest/ELF/resources. Installation extracts to isolated `/Apps/<id>/`, `/Drivers/<id>/`, `/Services/<id>/`, `/Providers/<id>/` or validated equivalent. Minimal ZIP decoder must bootstrap offline without installed service; ZIP service reuses primitives. Reject traversal, collisions, decompression bombs, corrupted data and unsafe replacement. Change all launch/resource paths; historical loose pairs remain bounded compatibility inputs only.

Only on EXPLICIT release requests read [docs/RELEASING.md](docs/RELEASING.md), `.github/workflows/release.yml`, current master/tag/version/releases. Existing mechanism updates `[riscrte] version` in `platformio.ini` and `.github/release-request.json` with corresponding `v` tag. Never publish as a build shortcut. Keep firmware output outside mutable `.pio`; versioned app `.bin` OTA/SD at 0x10000, merged `.bin` USB flash at 0x0, not OTA. Freeze and qualify final assets WITH OWNER DURING THIRD STEP, not intermediate development.
