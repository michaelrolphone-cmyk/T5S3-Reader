# U1 detailed validation and one owner hardware-test handoff

**Binding companion to [U1 milestone](NEXT_HARDWARE_TEST_MILESTONE.md).** Retains its E/F acceptance details under [four-milestone stream-first order](FOUR_MILESTONE_STREAM_FIRST_EXECUTION_ORDER.md), **[shared-chip and rail ownership](SHARED_CHIP_AND_RAIL_OWNERSHIP.md)**, [I²C bus ELF cutover](I2C_BOOTSTRAP_CUTOVER.md), [SPI/UART cutover](SPI_UART_ELF_BOOTSTRAP_CUTOVER.md) and [ELF verification performance](U1_ELF_LOAD_VERIFICATION_PERFORMANCE.md). U1 needs a stable installed I²C bus ELF and **assigned unique owners for chips/rails actually needed by USB/VBUS**, not a native I²C controller, full EPD/TPS power stack or GNSS/LoRa rail conversion. SPI/UART bus ELFs are U1 work only if a real U1 dependency needs them. Only owner starts physical qualification.

## Workstream E — integrate without intermediate owner tests

1. Test production package transactions, generic catalog/graph, registry/events, provider calls and stream rights: online/offline four kinds, missing catalog, snapshot mismatch, corrupt/missing/extra files, duplicate IDs/versions, invalid SHA/ELF/import, active replacement, interrupted recovery/remove, installed-not-activated, alternative `serial.port`, reconnect generations, competing clients, failed quiescence and no compiled USB fallback. Focus on durable invariants and demonstrated defects, not a broad E2E gate.
2. Audit linked firmware and ELF imports: reject normal firmware USB host/class/chipset/session/projection, hard-coded IDs/VIDs, special USB catalog and signing. **Bus rule:** installed matching I²C/SPI/UART bus ELF alone may import its own allowlisted temporary firmware raw-controller backend when needed. I²C ELF is mandatory U1; SPI/UART only when reached. Reject direct firmware bus imports/globals in any device ELF/app, firmware peripheral behavior, competing firmware-published bus capability and controller overlap. Document actual bus IDs, ABI, private imports, limits, ownership and U3 removal. USB CDC `serial.port` is distinct from physical `uart.port`; isolated ROM/diagnostic paths cannot provide normal UART/USB capabilities.
3. **Actual U1 power graph/physical-owner ledger:** inventory controller → chip physical instance/address → scoped output/rail dependencies → `board.power.vbus` → USB host, including verified profile, boot-alive prerequisite, single chip/register owner, pin grant, consumers, safe absence and teardown. `Drivers/board_power_t5s3_v2/driver.c` presently uses **BQ25896 `0x6B`** for USB OTG VBUS: one BQ owner handles OTG/charge arbitration; a future charger/telemetry feature cannot activate a second BQ register owner. If actual USB prerequisites require PCA9535 `0x20`, install one PCA register owner and grant **only** required output masks; preserve other pins and future button/EPD/radio ownership. TPS65185 `0x68` shares the I²C bus but is EPD HV/VCOM; do **not** require TPS/EPD to start USB absent schematic evidence. Reject conflicting address or PCA pin-output claims, duplicate power owners, unsafe BQ charge/OTG operation or a dependency cycle. Wiring not verified remains PENDING rather than invented.
4. Exercise I²C ELF startup with noncyclic power graph, bounded I/O/timeouts, exclusive controller, rights, corrupt/missing/disabled provider, revocation and safe rails. Dependent power/USB fails closed without I²C or chip/rail owner despite remaining firmware raw primitives. Consumer manifests require `i2c.bus`, not `kernel.i2c`, and work against a replacement provider of same ABI. **Host may not start before acquiring successful VBUS lease;** block conflicting OTG/charge actions, verify release/quiesce and prevent removal/update of owner with live dependents or uncertain shutdown. If PCA is used, masked writes cannot affect other outputs/button direction. Reject duplicate physical claims through opaque resource-key admission, not hard-coded chip policy in generic core. Apply matching bus absence/import/bounds checks to SPI/UART only if reached in U1; do not require native bus cutover yet. Full PCA button/EPD/radio concurrency is U3.
5. Run proportionate host tests, ZIP/package/ELF relocation/import audits, app/driver/firmware builds and release-equivalent staging where feasible; preserve firmware checksums outside mutable `.pio`. Include installed-generation hash/launch latency regression. Do not idle for CI; log actual PASS/FAIL/NOT RUN, never assert unperformed physical PASS and fix known blocking source defects before Work Complete.

## Workstream F — one owner hardware session after implementation

Provide matching firmware/apps/drivers/versions/ABI/assets, installation order (**I²C bus ELF → verified physical BQ VBUS and any actual PCA owner → USB ELFs**; SPI/UART only if actually required), board/power graph, SD backup, recovery and diagnostics:

1. Cold boot without optional USB ELFs: capability absent, UI/SD/manager functional, no fallback or unexpected VBUS. Install I²C bus, actual chip-owner dependencies, USB through common engine; confirm `i2c.bus`, `board.power.vbus`, graph and Serial Monitor `serial.port`, baud/DTR/RTS. Firmware raw I²C remains private to bus ELF.
2. Connect ESP32-S3-CAM CDC: sustained VBUS/boot, enumeration, actual probe, RX logs/TX, scrolling and reconnect. CP210x physical PASS only with real CP210x. Record unavailable variants.
3. Disconnect/reconnect, revocation, multi-client use, abort/unload, resource leaks and safe IRQ/DMA/host/power shutdown. Verify **one BQ register owner**, no OTG-versus-charge race, safe VBUS shutdown; if PCA participates verify one register owner and nonoverlapping allocated pin writes. Check bounded I²C faults and no duplicate owner. No premature EPD/TPS or GNSS/LoRa testing in U1.
4. Remove USB class/host: no firmware substitution. Remove I²C bus or required chip owner separately: dependent USB/power capability disappears or fails safely; no direct firmware escape. Test corrupt/missing/interrupted update preserving last good generation and refuse uninstall with unsafe live leases; inspect isolated boot/recovery. If U1 SPI/UART exists, verify the same fail-closed behavior and console isolation.
5. Exercise real non-USB witness and all four package kinds offline/online. I²C witness owns actual chip logic in its ELF and uses installed bus, never firmware I²C symbols. Do not infer cross-board hardware qualification.

Owner closes physical acceptance; discovered defects remain on one implementation PR. [Shared ownership](SHARED_CHIP_AND_RAIL_OWNERSHIP.md) assigns **U3** full PCA button/EPD/radio pin arbitration, sole TPS HV/VCOM owner and EPD sequencer, reuse of BQ charger/VBUS owner, and shared GNSS/LoRa rail leases with simultaneous-consumer/failure tests. U3 also replaces all three used bus ELFs' temporary internal backends with native controller ownership; U4 remains provisioning and one real image.
