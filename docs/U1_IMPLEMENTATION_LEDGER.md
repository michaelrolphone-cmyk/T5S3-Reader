## Generic runtime and installed hardware ownership

- Generic ELF byte/record streams, context-owned capability grants/revocation, bounded partial RX/TX and backpressure, verified provider discovery and API-aware dependency checks exist. USB stop (`3515ee0`–`a2035d4`) releases its own class/host grants, never shuts down the entire provider graph. Failure retains/quarantines exact module generations.
- The installed `i2c.bus` ELF alone may import the temporary bounded firmware I²C controller adapter. BQ25896 charger/USB power, physical IDF USB controller, USB host, CDC, CP210x and CH34x device-class implementations belong in their installable ELFs, not hardware-specific firmware drivers. Generic app target is `serial.port`, not `open_usb`.
- Host/class checked-release (`02ff428`–`fd94430`) appends `release_checked` to host discovery ABI without changing its initial prefix. A failed physical interface release pins its claim, disallows transfers, preserves class sessions, and retries failed-open orphans without closing other consumers. Host/CDC/CP210x regressions committed and wired; no full runner PASS observed at this head.
- Physical controller (`ca2c26f`–`5d9b5b5`) retains a two-stage `ClaimReleasePolicy.h`: a successful interface release followed by failed detached-device close retains the exact token and retries only unfinished close, never releases the same interface twice; unclaimed detached device handles are reaped by a bounded table. One isolated reconstructed C++17 ASan/UBSan policy exercise passed in an earlier continuation, **not** the full repository runner.
- **Selective master #105 integration (`db75070`, `e797bcc`, `e74ef8c`, `acdcbd9`, `6b7b41b`):** the real controller ELF now bounds bulk timeout cleanup to a 500-ms halt/flush/callback drain; it verifies a transfer belongs to the interface before release, preserves staged claim retry and drains DMA before freeing transfers, uninstalling the host or releasing VBUS. Undrainable bulk/control operations fail closed and remain pinned. It consumes IDF's final NO_CLIENTS event even when no device attached and permits verified faulted-state cleanup. A structural source regression is wired in the USB host runner, and an obsolete regression requiring global graph shutdown was corrected. This is **not verified by XTENSA build or physical measurement**.
- **Selective master #103 CH34x integration (`d534030`–`f63c2f8`):** imported actual chipset VID/PID matching, descriptor parser, WCH vendor control/baud/framing, DTR/RTS, bulk RX/TX and lifecycle as an independently installable `serial.port` ELF. Unlike the current master 0.1.0 implementation, this U1 0.1.1 class requires checked host ABI, returns failure and retains its session on failed close, quarantines failed-open orphan claims for bounded quiescence retry, and rejects legacy void-release-only hosts. Stable package identity `usb-ch34x-v2` is preserved; manifest builder, host protocol regression, existing USB runner and existing experimental CI all integrate this provider, with no fixed catalog whitelist. **Builds/tests are committed and wired, not observed passing.** CH34x remains a separate chipset class, not a duplicate canonical CDC identity.
