## Implemented stream, registry, and installed-provider foundations

- Generic ELF byte/record streams, cross-context rights, grant/revoke, provider I/O outside the stream mutex, and bounded partial-read/write handling. `open_usb` is unsupported; semantic `serial.port` streams are the intended app interface. `ClassStreamSession` and production `NativeStreamBridge` retain accepted RX/TX chunks through backpressure, partial/zero writes, and reconnect handling.
- Installed USB class binding with checked teardown, retained package pin on uncertain physical close, and removal of duplicate premature class attachment. The I²C bus ELF is the **only** authorized interim importer of bounded firmware `risc_fw_i2c_transact_v1`; fully native I²C controller backend belongs to U3. USB controller/host/class and BQ-VBUS physical ELFs exist but firmware USB orchestration is still a U1 blocker.

## Remaining U1 production work (not deferred to U2/U3/U4)

1. **BQ single-owner cutover:** connect the installed BQ charger's configuration, telemetry and shutdown interfaces to the actual battery/boot/sleep consumers. Remove all competing normal-runtime BQ register accesses and charger resets; allow only an explicitly bounded, one-way pre-runtime bootstrap if demonstrated necessary. Preserve charging/low-battery/recovery safety; missing ELF must fail closed. Verify no competing chip claims and actual sleep behavior.
2. **USB provider-originated discovery:** host ELF enumerates and publishes arrival/removal; class ELFs independently probe/bind and publish semantic `serial.port` and generic byte endpoints. Retire active firmware `NativeUsbBridge` polling, configuration/session/class selection, USB-specific registry projection/shuttles and `T5UsbApi` hardware fallback; preserve Serial Monitor/programmer DTR/RTS, partial I/O, cancellation and reconnect.
3. **Exclusive console/internal PHY:** verify linked handoff placement and implement narrow CPU/board port plus controller-ELF exclusive resource lease. On unsuccessful host teardown do not prematurely re-enable boot console or allow simultaneous ownership.
4. **USB-specific retirement and diagnostics:** structured provider failure fields instead of parsing `USBREF`/`USBCTRL`/`VBUSREF` text; reachability-based legacy CDC loader cleanup, class-neutral serial UI, and a fourth USB class installed without firmware changes.
5. **Package completion:** safe canonical legacy `usb-cdc-acm` identity/version migration, signing/P-256/security-floor path removal without weakening SHA/TLS/import/ABI/rollback, nested resources/per-kind roots, coherent version/installed guards, and preservation of unknown SD files.
6. **Performance and proof:** generation-bound ELF integrity receipts, avoid repeated complete ELF hashing on hot path, controller ELF linkage/admission, import/ID/catalog scans, host/build/release-equivalent validations and then owner-controlled physical qualification. Native I²C/SPI/UART backend takeover, unrelated peripherals and Wi-Fi belong to U3; CAM provisioning to U4.
