## Change

During SD-font paragraph advance preparation, keep the existing 4098-entry scratch array sorted as each codepoint is admitted. Binary search replaces repeated linear membership scans. Inserting a new distinct codepoint shifts at most 4096 entries; repeated codepoints do not shift entries. The admitted set remains the first 4096 distinct decoded values, and the scan stops at the same first new value beyond that cap. Existing final sorting, reserved space/hyphen slots, font/style resolution, cache saturation, allocation failures, glyph I/O and cleanup stay intact.

No new allocation or persistent cache is introduced. Membership is O(N log U), with a remaining bounded O(U²) insertion-movement cost, U≤4096. The regression counts shifted words independently: at the 4096 cap, ascending input moves 0, descending input moves 8,386,560, and the fixed shuffled case moves 4,216,630. The repeated 512-codepoint witness moves 0. These counts are checked against a separate inversion-count oracle. This does not claim universally linear runtime or a speedup for every input order. After 1024 decoded/shifted work units the scan checks elapsed time, yielding one RTOS tick only if 20 ms actually elapsed. Fast calls do not acquire a fixed sleep cadence. Each insertion is bounded by4096 shifted words; state spans word boundaries and handles clock rollover. Output, glyph metrics, rendering/layout, format and error decisions are unchanged; no timeout or approximation is introduced.
